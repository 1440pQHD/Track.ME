# Track.ME
Web-based goal tracker made to prevent procrastination and provide a clear overview of how close you are to achieving those goals coded in React.

# The idea

I'm going to be honest, I have a problem. Every time I want to start a big project like an RC plane or a Robot arm, I never finish it. I always run out of motivation, and it ends up sitting half-completed in the corner.

The reason?

Because I burn out after 3 days of working on it and I never have a clear overview of what I'm even trying to achieve. The tool I'm building will attempt to prevent said problem and help manage the load of projects.

# Features I want to implement

1. Create and delete widgets (working)
2. Draggable widgets for organization (working)
3. Implementing creation and deletion of different workspaces (working)
4. User login and sign-up
5. Implementing localstorage for saving of widgets (working)
6. Polished UI/UX elements with sound effects / visual effects
7. Dark mode / Light mode


# What is working right now?

You can create different workspaces, naming them and choosing an icon. Each workspace has its own goal widgets that are saved using localstorage.
